Neste modelo, deve-se usar os comandos $\backslash$cite para citar o trabalho e $\backslash$citeonline para citar o autor!!! \textbf{Não utilize} $\backslash$citet ou $\backslash$citep. Veja abaixo alguns exemplos:

Citando o autor:

Para análise de fadiga utilizando métodos baseados no domínio da frequênccia para históricos Gaussianos, o método proposto por \citeonline{dirlik1985} obtém resultados mais próximos do método Rainflow.


Citando o trabalho:

É notável que uma única distribuição Weibull não seja adequada para modelar PDF para fatores de irregularidade típicos de uma banda estreita. Para esses casos, uma distribuição de Rayleigh obtém resultados mais confiáveis \cite{zhao1992}.

Citação longa:

\begin{longquote}
    Um exemplo de citação longa nas regras da ABNT (4cm de recuo e fonte menor)
    feita com o ambiente  \verb|longquote|. A citação deve possuir letra com tamanho 10 e espaçamento simples, não deve ser escrita com aspas, é obrigatório que esteja referenciada a página de onde a citação foi retirada. Ademais, é necessário que haja uma linha em branco separando a citação dos parágrafos anterior e posterior. O ponto final deve ser colocado após a autoria, como pode ser visto~\cite[p.~83]{dos2018manual}.
\end{longquote}
